# 格间日记（Grid Diary）

Obsidian 里的「问题引导式」日记插件：**九宫格记录 + 右侧日历与列表 + 下方时间流**。
灵感来自九宫格 / 曼陀罗日记，数据全部是普通的 Markdown 文件，不锁定、不加密、随时可拔走。

## 一、它是什么

一天一个 Markdown 文件，文件里每个 `## 二级标题` 就是一个「格子」：

```markdown
# 2026-10-20

## 今日事件

今天去看了展览。

## 今日新知

Markdown 里的空行就是分段。

## 14:30 分笔记

上午临时记的一条。

## 15:10 分笔记

![[attachments/2026-10-20-4821.png|400]]
```

插件把 `## 今日事件`、`## 今日新知` 渲染成九宫格卡片；把 `## 14:30 分笔记` 这类**带时间戳**的小节渲染成下方的「时间流」。
你不需要改变任何书写习惯 —— 直接在 Obsidian 里写，插件负责展示。

## 二、功能

### 1. 九宫格
- 固定高度卡片（默认 200px，可在设置里调 80–400），内容超出**格内滚动**，文字始终靠顶。
- 同一行卡片等高；右下角可手动拖拽拉伸单张卡片。
- 就地编辑：点一下进入编辑，点外面自动保存，无需 `Ctrl+S`。
- 格式快捷按钮：`B` 粗体、`I` 斜体、`S` 删除线、`H` 高亮、`A` 红字；按钮不会抢走选区。
- 编辑态与预览态共用同一套字体/字号/行高，失焦不变样。
- 删除格子后弹出 5 秒「撤销」。
- 按住卡片左上角 `⠿` 拖动可换格子顺序，只重排该文件内的 `##` 小节，内容逐字不动。

### 2. 时间流
- 有内容的格子会实时镜像成卡片（打字 120ms 内跟上），清空即消失。
- 带时间戳的小节（`## HH:mm 标题`）独立成卡，可与格子并存。
- 手风琴折叠：点时间可收起 / 展开。
- **双击正文**进入原文编辑，`Ctrl+Enter` 或点外面保存回源文件。
- 每条右侧 `×` 可删除，带 5 秒撤销。
- 图片、音频、视频正常渲染；图片框可拖拽缩放，宽度会写回 `![[图片|宽度]]` 永久保存。

### 3. 右侧面板（日历 + 列表）
- 上方列表、下方日历，中间可拖拽调整比例，`⇕` 一键恢复 60/40。
- 按月视图：完整月历，有日记的日期带点；点日期弹出快捷菜单（打开日记 / 选择模板插入 / 插入图片）。
- 按日视图：按时间倒序列出全部日记，标题「10月20日 周二」+ 两行摘要，默认最近 200 篇，底部「加载更多」。
- 点击列表条目直接在主窗口打开格间日记并跳到那一天（不会打开原生 md）。
- 日期多色：年浅蓝、月浅紫、日浅橙，全局统一。
- 与主视图**双向日期联动**。

### 4. 模板
- 内置「格间六格」：今日事件 / 今日书账 / 今日新知 / 今日碎记 / 今日美食 / 今日反思。
- 设置里可 `+ 新增模板`（填名字和格子名），也可直接编辑文本批量改；每个模板可单独删除。
- 右上角「当前模板」下拉随时切换。
- 新建当天文件时可指定一个 Markdown 模板文件，支持变量替换：
  - `<% tp.date.now("YYYY-MM-DD") %>`、`<%% tp.date.now("ddd", -1) %>`
  - `{{date}}`、`{{date:YYYY年MM月DD日}}`、`{{time}}`、`{{time:HH:mm}}`、`{{title}}`
- 不依赖 Templater 是否安装；Templater 的高级 JS 语法不处理。

### 5. 设置
- 两个标签页：**常规设置** / **样式设置**。
- 常规：日记目录、自动补当天文件、列数、格子高度、当前模板、模板库、新建用模板文件。
- 样式：背景图、卡片透明度、字体、字重、上传字体文件（`.ttf/.otf`，≤4MB）、从 `.obsidian/fonts` 读取大字体、自定义 CSS（保存即生效）。

### 6. 自动与刷新
- 打开插件 / 点「今天」时，若当天文件不存在会**静默创建**（可在设置关闭）。
- 监听 vault 的 `modify` / `create` / `delete`，改完文件 350ms 内侧栏自动刷新。
- 自己写文件时会短暂忽略自身触发的刷新，避免「保存 → 重建 → 页面回弹」。

## 三、安装

### 方式一：手动安装（推荐，当前未上架社区市场）

1. 下载本仓库 Release 里的三个文件：`main.js`、`manifest.json`、`styles.css`。
2. 在你的 vault 里建目录 `.obsidian/plugins/grid-diary/`。
3. 把三个文件放进该目录。
4. 重启 Obsidian → 设置 → 第三方插件 → 找到「格间日记」→ 开启。
5. 左侧栏出现网格图标；或命令面板执行「打开格间日记」。

### 方式二：从源码构建

```bash
git clone https://github.com/<your-name>/obsidian-gezhi-diary.git
cd obsidian-gezhi-diary
npm install
npm run build     # 生成 main.js
```

然后把 `main.js`、`manifest.json`、`styles.css` 拷到 vault 的 `.obsidian/plugins/grid-diary/`。

## 四、快速上手

1. 设置 → 格间日记 → 确认「日记目录」（默认 `日记`）。
2. 打开格间日记视图，空页面点「用模板生成」，得到六格。
3. 直接在格子里写，点外面自动保存。
4. 右侧面板点日期切换；点日历数字可用当前模板追加笔记或插入图片。
5. 想看原始结构：格子上 `↗` 跳到文件中对应小节。

## 五、文件与目录约定

- 日记文件：`<日记目录>/YYYY-MM-DD.md`（**文件名必须是这个格式**，否则日历识别不到）。
- 图片：默认存到 `<日记目录>/attachments/`。
- 格子 = `## 二级标题`；时间流 = `## HH:mm 标题`。
- 插件配置存在 `.obsidian/plugins/grid-diary/data.json`（含模板、样式、上传的字体）。

## 六、已知限制

- **没有全局快捷键**：Obsidian 不提供插件级全局热键注册，键位由用户在快捷键设置里自行绑定。
- **移动端**：可安装，但拖拽换位、拖分屏等鼠标交互在手机上体验打折。
- **拖拽换位仅限同一天内**，跨文件移动未实现。
- **并发编辑**：如果你同时在原生编辑器里改同一篇文件并用插件自动保存，可能互相覆盖（未做三向合并）。
- **富文本**：以 Markdown 为准，不具备原生日记 App 那种按钮式所见即所得排版。
- 字体上传受 `data.json` 体积影响，单文件限 4MB；更大的字体请走 `.obsidian/fonts` 方案。

## 七、开发

```bash
npm run dev     # 监听编译
npm run build   # 单次编译
npx tsc --noEmit  # 类型检查
```

目录结构：

```
src/
  main.ts        插件入口：视图注册、命令、日期广播、vault 监听
  view.ts        主视图：九宫格、时间流、卡片编辑
  calendar.ts    右侧面板：日历 + 列表
  store.ts       文件读写：解析快照、小节增删改、图片宽度
  sections.ts    纯函数：解析 ## 小节、镜像、重排、段落转换
  settings.ts    设置页（两个 Tab）
  modals.ts      弹窗：新建格子、选模板、输入
  template.ts    模板变量渲染
  datecolor.ts   日期多色渲染
  types.ts       类型定义
```
