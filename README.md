# 格间日记（Grid Diary）

Obsidian 里的九宫格日记插件。灵感来自九宫格 / 曼陀罗日记与《晨间日记的奇迹》：
每个格子放一句问题当引导，写起来不费劲。

数据全部是普通的 Markdown 文件，不锁定、不加密、随时可以拔走。

## 一、它是什么

一天一个 Markdown 文件，文件里每个 `## 二级标题` 就是一个「格子」：

```markdown
# 2026-11-08

## 今日事件

今天去看了展览。

## 今日新知

Markdown 里的空行就是分段。

## 今日碎记

随手记一条。

<!-- gd-layout {"v":3,"cols":2,"skin":"magazine","border":"none","cover":"attachments/a.png","cells":[...]} -->
```

插件把 `## 今日事件` 这类标题渲染成九宫格卡片，正文一个字都不改。
不写插件也能正常读，装了插件只是换个看法。

## 二、主要能力

### 1. 九宫格

- 每格右上角一个 `＋`：在下方 / 右侧加一格、插入图片、插入动图、插入贴纸、插入片段、删除这一格。
- 空格子显示引导问句（晨间 / 日间 / 夜间三套），写着写着就有话说了。
- 打字时格子微微抬起，有手感。
- 就地编辑，点外面自动保存。
- 格式栏：粗体、斜体、删除线、高亮、颜色、图片、动图、附件。
- 格子可以拖拽排序、拖右下角改大小、设强调色。

### 2. 三种排布

- 上下滚（默认）
- 左右滚
- 左右翻页（带页码和「全宽」按钮）

格子宽度、每屏几列、每行几行都能调。

### 3. 页面外观

- **六种风格**：现代卡片 / 手账纸感 / 杂志留白 / 便当格 / 极简黑白 / 自定义。
- **四种格子边框**：无 / 细线 / 双线 / 虚线。
- **封面**：可换图、可拖动取景、可拖高度（60–1200px）、可设兜底图。
- **贴纸**：天气 / 心情 / 标签三组，整篇最多 5 个，单格 1 个。
- **裁剪**：选完图可以像微信头像那样框选，只存坐标不剪原图。封面、头像、照片层、日历底图都支持。

### 4. 图层舞台

封面区是一个可以一层层往上叠的舞台：

- 背景层、照片层、座右铭层、标志层
- 每层可以是纯色、渐变、图片、动图、视频
- 每层能拖、能缩、能调透明度、能设叠加方式
- 层数不设上限

### 5. 图片与视频

- 支持 `png / jpg / jpeg / webp / svg / bmp / avif`
- 动图 `gif / webp / apng` 直接播放
- 视频 `mp4 / webm / ogv / mov` 当壁纸（静音循环，需要手动打开开关）
- 轮播壁纸：选一组图，按每次打开换或定时换
- 底图可以按月、按周自动换色

### 6. 日历

- **五种骨架**：月网格 / 周条 / 纵向年历 / 大日期 / 双栏月历（外加双月并排）
- **六种纹理**：无 / 方格纸 / 点点阵 / 细横线 / 纸纹 / 渐变
- **底图四摆位**：左上角 / 右下角 / 双角 / 整块铺满
- **内置农历**：1900–2100 的农历、节气、节日，运行时零依赖
- 点日期先出预览卡（不跳转），双击才进。已经写过的那天会问「再写一篇 / 打开已有」
- 可以放在标签页，也可以做悬浮窗

### 7. 目录

- 搜索框 + 「文件夹」三个字（点开是菜单）
- 上下双面板：上面文件夹树，下面该文件夹的笔记
- 每条笔记前面一个小图钉（取当天的图或封面）
- 今天 / 昨天 / 前七天 / 更早 自动分组
- 每个文件夹可以有自己的颜色和表情图标
- 拖拽移动、右键移动到…、紧凑模式、隐藏名单、篇数与字数

### 8. 流线图

- 竖轴贴左、卡片占满整宽的**单列**排法
- 按年分段，点任意一行直接开这一天的浮窗
- 显示缩略图、字数、改过几次
- 可放右侧栏，也可做浮窗

### 9. 悬浮窗

- **灵感笔记**：随手记，`Ctrl+Shift+G` 唤起
- **日历浮窗**：纯色底、可调透明度与磨砂、可拖可缩放
- **流线图浮窗**：可多开，位置会记住

### 10. 主题系统

一个主题管全部视觉，存在 vault 的 `主题/` 文件夹里，是普通 JSON，可以备份、可以回滚。

- 七组参数：底色 / 字体 / 线体 / 图标 / 格子 / 排版 / 动效
- 六套预设：宣纸 / 极简白 / 夜航 / 手账 / 杂志 / 便当
- 每个主题带版本号和改动记录，能回滚到任意一版
- 切换项目时视觉可以一起换

### 11. 正文排版

按纸书的规矩来：

- 首行缩进 2em（可调 0–4）
- 段落间距 0.8em（可调 0–2）
- 标题下方间距 0.5em（可调 0–1.5）
- 标题、列表、引用、表格不受缩进影响

### 12. 粘贴与模板

- 粘贴自动识别：标题 / 表格 / 分隔符 / 空行分段
- 同名标题自动合并，不会被切成「片段 1、片段 2」
- 按当前模板对齐，模板里没写的格子留空
- 格式过滤、关键词过滤
- 模板分六类：主页 / 目录 / 日历 / 悬浮窗 / 格子 / 表格
- 可以只存标题，也可以连内容一起存

### 13. 历史

- 每次改动前自动留快照
- 按天查看、对比、一键回退
- 恢复删除

## 三、安装

### 手动安装

1. 下载 Release 里的 `main.js`、`manifest.json`、`styles.css`
2. 放进 `<你的库>/.obsidian/plugins/grid-diary/`
3. 重启 Obsidian → 设置 → 第三方插件 → 找到「Grid Diary」→ 开启

### 从源码构建

```bash
git clone https://github.com/3388038686-oss/obsidian-gezhi-diary.git
cd obsidian-gezhi-diary
node build.mjs        # 生成 dist/main.js
```

构建脚本零依赖，只需要 Node。它会把 `src/` 下按 `NN-名字.js` 命名的分片按序拼起来，做一次语法校验，再输出到 `dist/`。

### 测试

```bash
node test.mjs       # 纯逻辑（解析、迁移、模板、粘贴、裁剪换算）
node smoke.mjs      # 插件级（加载、视图注册、命令）
node domsmoke.mjs   # 渲染级（真跑 dist/main.js，用假 DOM 断言元素）
```

## 五、数据格式

每个日记文件末尾有一行注释保存布局，正文完全不受影响：

```html
<!-- gd-layout {"v":3,"cols":2,"skin":"magazine","border":"none",
                 "cover":"attachments/a.png","coverHeight":160,
                 "coverPos":"50% 50%","crops":{"cover":{"x":0,"y":0,"w":80,"h":100}},
                 "layers":{...},"cells":[{"cs":1,"rs":1,"h":0,"accent":"","collapsed":false}]} -->
```

- `v:3` 是当前版本，老文件（v1 / v2）能读，只有你改过才会升级写回
- `crops` 存裁剪框，是原图百分比，不剪原图
- 删掉这行注释也不影响阅读，只是会丢掉布局
